# Measured scientific quantities

`costs.py` separates first-goal SOC/makespan, recorded actions, individual static shortest-path detour, paper Eq.2 reference and certified optimality gap. `communication.py` accumulates actual recipient payloads, broadcasts, bytes and signed balances online. Spatial and space-time disclosures differ; missing historical observations are not reconstructed as measured communication. `evaluator.py` retains a legacy sharing proxy; use `communication.py` for measured delivery counts.

See [metric definitions and denominators](../../../docs/METRICS.md).
