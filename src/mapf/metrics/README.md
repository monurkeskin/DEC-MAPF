# Measured scientific quantities

`costs.py` separates first-goal SOC/makespan, recorded actions, individual static shortest-path detour, paper Eq.2 reference and certified optimality gap. `communication.py` accumulates actual recipient payloads, broadcasts, bytes and signed balances online. Spatial and space-time disclosures differ; missing historical observations are not reconstructed as measured communication. The old evaluator remains a compatibility proxy and cannot qualify current figures.

See the [current contract](../../../docs/METRICS.md), the source interfaces and executable tests.
