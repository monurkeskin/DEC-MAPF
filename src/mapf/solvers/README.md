# Python solver adapters

CBS, simplified focal CBS, Prioritized Planning and decentralized strategy adapters share independent validation. Legacy EECBS identifiers do not certify published EECBS bounds. Expansion/process limits are effective inputs; incomplete search does not prove infeasibility. External binary adapters require declared semantics and retain SHA/process/parser receipts; a parser fixture is not oracle certification.
