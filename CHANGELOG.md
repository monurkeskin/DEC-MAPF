# Changelog

## 0.1.0a1 — Alpha

Initial Python alpha of the DEC-MAPF simulation and experimentation framework, with decentralized negotiation methods from the JAAMAS 2024 and EUMAS 2021 papers, centralized solvers and shared research workflows.

- Headless studies with immutable manifests, explicit attempt history, process isolation, bounded execution, resume and all-outcome exports.
- HeatMap and PathAware strategies, versioned token negotiations and SC/DC/ZC commitment semantics across four physical settings.
- Independent trajectory validation, explicit failure categories and common-solved comparisons.
- Optional local GUI for configuration, execution, discrete replay, agent/negotiation inspection, local observations, decision heat, commitments and exports.
- Supported Python API, typed solver extension contracts, portable teaching capsules and study scaffolding.
- Optional native solver adapters with explicit executable identity, upstream licensing and capability checks.
- Local searchable documentation and six real GUI images of validated 80-agent solutions from the article settings, with recorded provenance.
- Python and browser acceptance, source/wheel identity checks and source-free installed-package workflows in CI.

The import and CLI name is `mapf`. See [compatibility](docs/COMPATIBILITY.md) for API and bundle versions. Alpha qualification does not establish historical numerical equivalence; see [scientific scope](docs/ALPHA-STATUS.md), [algorithm semantics](docs/ALGORITHM.md) and [reproducibility](REPRODUCIBILITY.md).
